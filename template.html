{%- comment -%} The payload carries several screens' worth of events. Which one is shown is derived from the render clock, so the display keeps rotating between pushes rather than only when new data arrives. A missed or delayed push therefore costs freshness, not movement. trmnl.system.timestamp_utc is the render time.
